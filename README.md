# Instalar dependencias

```bash
pip install -r requirements.txt
```

# Ejecutar el servicio de autenticación en modo desarrollo

```bash
uvicorn server:app --reload
```

# Ejecutar el servicio de ventas en modo desarrollo

```bash

python server.py
```

# Pasos para ejecutar el proyecto

1. Clonar el repositorio.

2. Instalar dependencias para el backend y frontend.

3. Configurar las variables de entorno necesarias para la conexión a la base de datos y otros servicios.

4. Correr el docker-compose para levantar los servicios de base de datos

5. Correr el sql de postgreSQL para los valores por defecto las tablas necesarias.
